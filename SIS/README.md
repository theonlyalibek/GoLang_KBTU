# СИС 1 — калькулятор доставки

Программа на Go 1.27, которая считает стоимость доставки по весу посылки и зоне. Можно создать несколько заданий, обработать их и посмотреть результаты.

Всё хранится в памяти. После выхода из программы задания не сохраняются.

## Как запустить

Команды нужно выполнять из папки `SIS`.

Для работы через меню:

```powershell
go run ./cmd/delivery -interactive
```

В меню есть такие пункты:

```text
1. Создать доставку
2. Показать все задания
3. Обработать задание по ID
4. Посмотреть задание по ID
0. Выход
```

Сначала создаёшь доставку: вводишь вес в граммах и зону — `city` или `intercity`. Она получает ID и статус `pending`. Потом выбираешь пункт 3 и вводишь этот ID, чтобы посчитать стоимость. В списке задания идут по порядку ID.

Например, можно создать две доставки и обработать только вторую. У первой останется `pending`, а у второй уже будет результат.

Для одного расчёта можно сразу передать данные через флаги:

```powershell
go run ./cmd/delivery -weight 1500 -zone city
```

В этом режиме доставка создаётся и сразу обрабатывается. Без флагов запускается пример с весом 1500 г и зоной `city`. Справка открывается через `-h`. Флаг `-interactive` используется отдельно от `-weight` и `-zone`.

## Как считается цена

Тарифы условные, для этого проекта:

| Зона | Базовая цена | За каждый начатый кг |
| --- | ---: | ---: |
| `city` — по городу | 500 ₸ | 300 ₸ |
| `intercity` — между городами | 1000 ₸ | 500 ₸ |

Вес округляется вверх до целого килограмма. То есть 1000 г — это 1 кг, а 1001 г — уже 2 кг.

Например, для 1500 г по городу получается:

```text
Расчётный вес: 2 кг
Стоимость: 500 + 2 × 300 = 1100 ₸
```

Вес и деньги хранятся целыми числами `int64`, без дробных значений.

## Что происходит с заданием

У каждого задания есть ID, входные данные, статус и результат.

```text
pending -> processing -> completed
                     -> failed
```

`pending` — задание создано, `processing` — идёт расчёт, `completed` — результат готов. Если калькулятор вернул ошибку, будет `failed`. Обработать можно только задание со статусом `pending`.

Нулевой или отрицательный вес и неизвестная зона не принимаются. Если ввести несуществующий ID или повторно обработать готовое задание, программа вернёт ошибку. В меню после обычной ошибки можно продолжить работу.

## Где что находится

- `delivery/task.go` — данные задания, статусы и проверка входа.
- `delivery/calculator.go` — интерфейс `Calculator` и расчёт по тарифам.
- `delivery/service.go` — создание, поиск, список и обработка заданий.
- `cmd/delivery/main.go` — запуск и флаги.
- `cmd/delivery/menu.go` — меню и ввод данных.
- Файлы с окончанием `_test.go` — тесты.

Задания хранятся в `map[int]Task`. Метод `List()` собирает их в слайс и сортирует по ID. При получении задания возвращается копия, поэтому её изменение не меняет сохранённые данные. Интерфейс `Calculator` отделяет расчёт цены от хранения и обработки заданий.

## Проверка

```powershell
gofmt -l .
go build ./...
go vet ./...
go test ./...
```

Тесты проверяют тарифы и округление веса, создание и поиск заданий, ошибки, смену статусов, список и работу с несколькими доставками. Есть table-driven tests. При `gofmt -l .` список файлов должен быть пустым.
